# Browser protection

Install **Highflame Browser Security** and connect it to your Highflame tenant. The
extension is the same in every browser; only the install-and-enable steps change.
Pick the guide for the browser you are connecting:

| Browser | Guide |
| --- | --- |
| **Google Chrome** (also Edge, Brave, Opera) | [chrome.md](chrome.md) |
| **Mozilla Firefox** | [firefox.md](firefox.md) |
| **Apple Safari** | [safari.md](safari.md) |

Each guide covers install, the Studio API key, and the three Settings fields the
extension needs (**API Key**, **Shield Endpoint**, **Token Endpoint**).
